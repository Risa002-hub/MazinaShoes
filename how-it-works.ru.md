# Как устроен проект «Чудо Обувь» (для вас, не для программы)

Приложение для экзамена: каталог обуви, вход по логину, оформление заказа, заказы для менеджера и администратора.

## Как идёт работа с проектом
| Что происходит | Кто делает | Какие файлы меняются |
|---|---|---|
| Новая функция | Claude пишет код, вы смотрите пояснения | страницы `*Page.xaml` и `*Page.xaml.cs` |
| Изменилась база данных | Вы обновляете модель в Visual Studio (правый щелчок по `MazinaShoesModel.edmx` → «Обновить модель») | `MazinaShoesModel.edmx`, классы таблиц (`Product.cs` и др.) |
| Нужно своё вычисляемое свойство | Пишется в `Partials.cs`, а не в `Product.cs` (тот файл Visual Studio может создать заново) | `Partials.cs` |

## Где что лежит
- `Manager.cs` — общие данные приложения: рамка со страницами, вошедший пользователь, корзина.
- `LoginPage` → `ProductPage` (каталог) → `ProductDetailsPage` (товар) → `CartPage` (корзина).
- `OrdersPage` → `OrderDetailsPage` — только для менеджера и администратора.
- `AnalyticsPage` — только для администратора: заказы, сумма и топ-5 за период, экспорт в PDF через встроенный принтер Windows «Microsoft Print to PDF» (без пакетов).
- `Partials.cs` — скидка, «много/мало», подсветка, ФИО.

## Роли (таблица Role)
1 — администратор, 2 — менеджер, 3 — авторизованный пользователь. Без входа — гость: видит только каталог.
